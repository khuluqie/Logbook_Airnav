# Sistem Informasi Logbook Kegiatan Teknisi Unit CNSD

Project KP: Implementasi Sistem Informasi Logbook Kegiatan Teknisi pada Unit CNSD AirNav Indonesia Cabang Pekanbaru.

## Teknologi
- PHP 8+
- MySQL/MariaDB
- Bootstrap 5

## Instalasi XAMPP
1. Salin folder `logbook_cnsd_airnav` ke `C:/xampp/htdocs/`.
2. Jalankan Apache dan MySQL dari XAMPP.
3. Buka phpMyAdmin.
4. Import file `database.sql`.
5. Buka `http://localhost/logbook_cnsd_airnav/`.
6. Login dengan:
   - Username: `admin`
   - Password: `admin123`

## Modul
- Login/logout
- Dashboard
- Data teknisi
- Data perangkat
- CRUD logbook
- Pencarian logbook
- Detail dan cetak logbook

## Catatan KP
Data perangkat dan kegiatan di database adalah data contoh/dummy untuk pengembangan aplikasi. Jangan memasukkan data operasional atau informasi sensitif AirNav ke aplikasi tanpa izin.
